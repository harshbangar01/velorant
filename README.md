# Velorant

A dynamic, visually immersive gaming website inspired by Riot Games' **VALORANT**.  
Showcasing agents, weapons, maps, live matches, and the latest news—all in a modern, responsive design.

## Features

- **Agents Showcase:**  
  Explore detailed profiles of iconic agents, including their roles, abilities, and stats.

- **Weapons Gallery:**  
  Browse the tactical arsenal with images, stats, and featured weapons.

- **Battlefield Maps:**  
  View interactive map cards with unique features and descriptions.

- **Live & Upcoming Matches:**  
  Follow featured matches, live scores, and upcoming esports events.

- **Player Stats:**  
  Track performance metrics and competitive progress.

- **Latest News:**  
  Stay updated with patch notes, esports news, and interviews.

- **Responsive Design:**  
  Optimized for desktop and mobile devices.

## Tech Stack

- **HTML5**  
- **CSS3** (custom, no frameworks)  
- **JavaScript** (vanilla, no frameworks)

## Getting Started

1. **Clone or Download the Repository**
2. Open `index.html` in your browser.

No build tools or dependencies required.
